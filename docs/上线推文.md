【版本 A】主推版（公众号推文 / 小红书正文）

灵感这东西，一转身就没。

洗澡时想到的一句文案，地铁上冒出的一个点子，跟人聊天时灵光一现——当时觉得「这我肯定忘不了」，半小时后干干净净。

所以我做了这个微信小程序：灵感随时记。打开就是输入框，没有标题、没有分类、没有必填项，想到什么写什么。不方便打字就按住说一段，松手自动保存；看到想留住的画面就拍一张，几张都行。

它只做三件事：让你 3 秒内开始记，不打断思路；所有内容存在你自己手机里，不注册不登录，不用了删掉即走，数据不经过任何服务器；过了几天忘了？「重温」随机翻出一条旧的，让你和当初的自己再碰一次头。

另外支持全文搜索、一键做成图分享、备份导出。微信里搜「灵感随时记」就能用。

不用下载 App，不用记账号。灵感来的时候，它刚好在。
