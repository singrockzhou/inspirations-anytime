# 个人主体上线材料清单与填写要点

> 适用：灵感随时记，个人主体，纯本地工具类小程序。
> 规则以微信公众平台后台实际可选项为准；本清单整理自 2026 年公开规则与备案实操。

---

## 零、起点纠正：项目一直挂在「国色天湘香菜」的 AppID 上

2026-11-11 用「公众平台安全助手 → 绑定查询 → 小程序」查到的全部归属如下：

| 显示为 | 原始 ID / AppID | 真实身份 | 与本项目的关系 |
|---|---|---|---|
| 国色天湘香菜 | `gh_464244c7d0be` / **`wxa12c398753852198`** | 一个**正式的**小程序账号（可登录后台、有版本管理） | ⚠️ **项目当前绑的就是它**。所有历史版本、预览码都传进了这个账号的开发版本槽位 |
| 灵感随时记**的试用小程序** | `gh_689d5de3b3e1` | 第三方服务商代建的试用小程序，已授权第三方 | 与本项目无关，也从没被上传过代码 |
| singsockzhou 的小程序测试号 | `gh_5f02999dca32` | 开发者工具「测试号」 | 不占名额、不能发布。**可以当过渡期的预览环境** |
| singsockzhou 的小游戏测试号 | `gh_d4dbeb1366e0` | 同上 | 同上 |

**为什么这很危险**：`project.config.json` 里的 `appid` 决定代码传给谁。写在国色天湘香菜上，
上传是往那个餐厅小程序里塞开发版本；一旦在它的后台点「提交审核 → 发布」，
它的线上版本就会被换成灵感随时记的代码——那是不可逆的线上事故。

**实际风险（2026-11-11 已核实，比上面想的小）**

小程序助手「版本查看」里只有一块「预览版：Zhou 提交 11/11 19:59」，**没有线上版本、
没有审核中版本、没有体验版**——这个账号从未发布过。所以不存在"覆盖线上"的问题，
最坏情况只是它的开发版本槽位里躺着一份灵感随时记的代码。

**顺手清三件事**

1. **别在这个后台点提审、点发布。** 上传、选为体验版都无害，只有提审 + 发布才会把它的
   版本换成灵感随时记。
2. **删掉那份开发版本**：PC 扫码登录 `mp.weixin.qq.com` → 管理 → 版本管理 → 开发版本 → 删除。
   小程序助手里的「预览版」记录不用管，那只是最近一次预览的痕迹，改不掉也不碍事。
3. **开发者工具先换成「测试号」**：项目 → 项目设置 → 基本信息 → AppID → 测试号。
   测试号能预览、能真机调试，本项目纯本地不联网、不调任何服务端接口，够用；
   等正式号下来再换成正式 AppID。这样后续调试不再往别人的账号里传东西。

**要不要直接复用它？不建议。** 已确认（2026-11-11）它是本人早期做测试用的账号，
不涉及第三方，所以"主体不属于本人"这层顾虑不存在了。但真正的理由变了——

这次的混乱本身就是答案：你有两个正式号、一个试用号、两个测试号，结果灵感随时记的代码
传进了餐厅账号，而你以为自己在测灵感随时记。**复用会让"测试用"和"要发布"继续是同一个号，
下次还会混。** 加上两个硬成本：① 个人主体一年只有 2 次改名，且「国色天湘香菜」这个名字
一旦改掉就被释放，谁先注册归谁；② 餐饮类目转工具类目，备案信息要变更，等于重走一遍备案。

用 10 分钟的注册换取"一个账号只对应一个项目"，值。

**结论：名下没有「灵感随时记」的正式小程序账号，必须先注册一个。**

**备案期怎么给人试用**：等备案号是 7–20 个工作日，但**体验版不需要备案**。注册完立刻
上传 → 后台「版本管理 → 选为体验版」→ 加体验成员（上限 15 人），这期间就能正常发给朋友看。
备案号下来后再走「提交审核 → 发布」。

### 迁移六步（按顺序，卡点在 ③ 和 ⑤）

| 步 | 做什么 | 耗时 | 卡点 |
|---|---|---|---|
| ① | 注册正式个人小程序：`mp.weixin.qq.com` → 立即注册 → 小程序 → 用**从未注册过微信产品的邮箱** → 主体类型选「个人」→ 身份证 + 人脸 + 手机号 | 10 分钟 | 邮箱被占用会直接失败 |
| ② | 拿到新 AppID（`wx` 开头），改开发者工具「项目 → 项目设置 → 基本信息 → AppID」；或直接改 `project.config.json` 的 `appid` | 1 分钟 | 改完要重新编译 |
| ③ | 填基本信息：名称「灵感随时记」、头像、简介（见第四节）、服务类目「工具 → 效率」、10 个关键词 | 15 分钟 | 名称被占用需换名或申诉 |
| ④ | 填「用户隐私保护指引」：麦克风、相册、剪切板三项必须勾，否则真机 `wx.getClipboardData` 直接 fail | 10 分钟 | 漏勾 = 功能在真机静默失效 |
| ⑤ | 提交 ICP 备案（后台 → 设置 → 基本设置 → 小程序备案） | 30 分钟填报，**7–20 个工作日**审核 | 全流程最长的一环，越早提交越好 |
| ⑥ | 开发者工具「上传」→ 后台「版本管理」→ 提交审核 → 通过后「发布」 | 上传 5 分钟，审核 1–3 天 | 备案号下来之前提交审核会被拦 |

> 试用小程序到期只会注销它自己，**不影响**正式号的备案与发布；但试用期一旦结束，
> 旧 AppID 失效，开发者工具的预览码也跟着失效。所以 ① ② 要尽快做完，别等备案。

### 两个必须知道的副作用

1. **换 AppID = 换沙箱**。小程序的数据是按 AppID 隔离的，试用期在真机上记的那些内容
   不会迁移到新号里，新号首次打开是空库。代码零改动，只是数据从零开始——反正那些只是测试数据。
2. **WorkBuddy 发布面板里还挂着试用版**。要在这里改用正式号，需先在分享面板点「解绑」，
   再选「绑定已有小程序账号」用管理员微信扫码授权。若打算完全自己用开发者工具上传，
   这一步可以跳过，两边互不影响。

## 一、先确认个人主体能做什么

| 项 | 个人主体 |
|---|---|
| 注册门槛 | 身份证 + 实名微信 + 手机号 + 邮箱，免费，人脸核身 |
| 数量上限 | 同一身份证最多注册 **5 个**小程序；备案名额同样受限 |
| 微信支付 | **不可用**（本项目不需要） |
| 直播 / 卡券 / 获取手机号 | 不可用（本项目不需要） |
| 服务类目 | 仅开放工具、查询、部分生活服务等"非经营、低风险"类目 |
| 微信认证 | 个人主体通常无法完成认证；不影响发布，只是没有认证标识、搜索权重略低 |
| ICP 备案 | **必须**，未备案不能发布 |

本项目的功能（记文字 / 录音 / 照片、本地存储、导出备份）**完全落在个人主体的能力范围内**，没有需要额外资质的内容。

## 二、材料清单（逐项准备）

### 1. 主体与负责人材料

| 材料 | 要求与要点 | 常见驳回原因 |
|---|---|---|
| 本人身份证（人像面 + 国徽面） | 原件拍摄，四角完整、无反光、不翻拍、不加水印；建议 100–200 KB | 模糊、缺边、反光、翻拍 |
| 人脸核身 | 微信扫脸，需本人操作，光线充足 | 非本人、环境过暗 |
| 纯白背景核验照 | **部分省份要求**，白墙前免冠正拍，人像完整 | 背景杂乱、有阴影、戴帽 |
| 手机号 | 必须本人实名、与备案填写一致、能收短信 | 号码未实名 / 与填写不一致 |
| 邮箱 | 未被其他备案占用 | 邮箱已被占用 |
| 应急联系人 | **另一位**可联系的人，姓名 + 手机号，不能与负责人完全相同 | 缺填、与负责人重复 |

### 2. 小程序信息

| 项 | 规则 | 本项目的填法 |
|---|---|---|
| 名称 | 4–30 个字符（1 个汉字 = 2 字符，即 **2–15 个汉字**）；每年 2 次改名机会；不得含"微信/官方"、他人商标、医疗金融新闻等敏感词；个人不得用企业字号 | 「灵感随时记」（5 字 = 10 字符，含核心词"灵感"+"随时记"） |
| 头像 | 正方形，建议 1024×1024 PNG，无微信元素、无二维码、无联系方式 | 一张暖白底 + 陶土橙的记录本/笔触图标，与小程序内主色 `#C4713F` 一致 |
| 简介 | 4–120 个字符（1 个汉字 = 2 字符，即 **≤60 个汉字**）；前 20 字是抓取重点；修改次数有限，**定稿再提交** | 见第四节四个备选 |
| 服务类目 | 与实际功能一致，选错直接驳回 | 一级「工具」→ 二级「效率」；若后台无"效率"，次选「工具 → 记事本 / 笔记」，再退「生活服务 → 生活助手」 |
| 自定义关键词 | 最多 10 个，每月有限次修改且需审核；不要填竞品名、不要堆大词 | 见第四节关键词建议 |
| 小程序简称 | 可选，用于搜索结果展示 | 可留空，或填「灵感记」 |

### 3. 隐私合规（硬门槛，缺了真机直接调不通）

在「设置 → 服务内容声明 → 用户隐私保护指引」里提交，**必须勾选并写明用途**：

| 接口 | 对应隐私项 | 用途写法（直接抄） |
|---|---|---|
| `wx.getRecorderManager` | 麦克风 | 用于录制语音灵感，录音仅保存在你的手机本地，不上传 |
| `wx.chooseMedia` / `wx.previewImage` | 相册（选中的照片） | 用于选择照片作为灵感配图，仅保存在本地 |
| `wx.getClipboardData` | 剪切板 | 用于把你刚复制的文字一键存为一条灵感；只在你主动点击时读取 |
| `wx.setClipboardData` | 剪切板（写入） | 用于复制灵感文字/联系方式 |
| `wx.saveFileToDisk` / `wx.shareFileMessage` | 不涉及隐私，但需真机验证 | 导出备份文件 |

> 注意：**剪切板是隐私接口**。指引没勾「剪切板」，真机上 `wx.getClipboardData` 会直接 fail，功能表现为"点了没反应"。

### 4. ICP 备案材料

| 项 | 说明 |
|---|---|
| 入口 | 微信公众平台小程序后台 → 首页"去备案"提示，或「设置 → 小程序备案」 |
| 费用 | **免费**（任何"代备案收费"都是信息差） |
| 周期 | 平台初审 1–2 工作日 → 工信部短信核验 → 通信管理局 1–20 工作日，合计约 **7–20 个工作日** |
| 短信核验 | 来自 **12381**，收到后 **24 小时内**必须完成，超时作废需重报 |
| 服务内容 | 选 1–2 个，与实际一致：「工具类 / 信息记录」；不涉及前置审批的行业选"以上都不涉及" |
| 结果 | 通过后备案号自动展示在小程序「更多资料」页，无需手动添加 |

## 三、提交顺序（照这个顺序不会卡）

```
① 注册正式个人小程序（必做——现在名下只有试用小程序，见第零节）
      ↓
② 填基本信息：名称 → 头像 → 简介 → 服务类目 → 关键词
      ↓
③ 提交《用户隐私保护指引》（勾麦克风/相册/剪切板）
      ↓
④ 提交 ICP 备案（等 7–20 个工作日）
      ↓
⑤ 开发者工具「上传」代码 → 后台「提交审核」
      ↓
⑥ 审核通过（通常 1–7 天）→ 点击「发布」
```

备案和开发可以并行：备案期间用**体验版**测试和演示，不影响。

## 四、简介备选（4 版，均 ≤60 汉字 / 120 字符）

### 版本 A · 功能直白型（推荐，搜索最稳）

> 随手记灵感：说一句、拍一张、写两行，按天自动归档。标签、搜索、那年今日随时翻得到。只存本机，免登录。

- 字数：50 字 / 100 字符
- 亮点：前 12 字把「灵感 + 三种记录方式 + 自动归档」说完，覆盖"灵感""随手记""归档"三个搜索词；结尾的"只存本机，免登录"是差异化卖点——同类笔记应用绝大多数要求登录并上传。
- 适合：作为默认简介，最不容易被审核挑问题。

### 版本 B · 场景痛点型（最抓人）

> 好句子只在脑子里存三秒。说一句、拍一张，两秒记下，不用起标题、不用选分类。想翻的时候，它就在。

- 字数：48 字 / 96 字符
- 亮点：不描述功能，先描述"灵感会丢"这个瞬间，再给动作。转化率高，但搜索词覆盖弱于 A。
- 适合：放在朋友圈/公众号引流文案的配套介绍，或 A 之外的第二选择。

### 版本 C · 关键词密集型（搜索覆盖最广）

> 灵感记录与语音速记：一句话、一张照片都能存，自动按天整理，支持标签和全文搜索。私密存本机，不联网不上传。

- 字数：52 字 / 104 字符
- 亮点：一次覆盖"灵感记录 / 语音速记 / 备忘 / 标签 / 搜索 / 私密"六个词；"不联网不上传"直接回应隐私顾虑。
- 适合：同类竞品多、需要靠搜索长尾吃饭时用。

### 版本 D · 极简调性型

> 想到就记，不必整理。语音、照片、一句话都行，它自己按天收好。

- 字数：30 字 / 60 字符
- 亮点：最短、最像产品而不是广告，与小程序内部的文案调性一致（"不用起标题，也不用选分类"）。
- 适合：品牌感优先、不指望搜索时用。

**建议**：默认用 **A**（搜索与信息完整度最平衡）。如果后台提示"简介不可修改"，务必先用 A 提交。

## 五、关键词建议（后台可填 10 个）

按「3 核心 + 4 功能 + 2 场景 + 1 同义」配比，避免全是同类大词：

| 类型 | 建议词 |
|---|---|
| 核心（3） | 灵感、随手记、速记 |
| 功能（4） | 语音备忘、照片记录、标签管理、全文搜索 |
| 场景（2） | 闪念、想法记录 |
| 同义（1） | 备忘录 |

不要填：竞品小程序名、无关大词（"记账""外卖"）、"微信"等违规词。

## 六、高频驳回原因与本项目的对策

| 驳回原因 | 本项目对策 |
|---|---|
| 页面空白 / 功能不完整 | 首次打开是空列表（本地工具的正常状态）。按第七节备注说明并给验证路径 |
| 类目与实际功能不符 | 用「工具 → 效率」，功能就是记录与管理，不含交易、社交、资讯 |
| 隐私指引未声明即调用 | 麦克风、相册、剪切板三项先提交指引，再提审 |
| 简介/名称含敏感词或行业词 | 现名与简介都不含"教育/医疗/金融/官方"等词 |
| 未备案 | 先备案再提审（后台会拦） |
| 证件照不合格 | 原件拍摄、不翻拍、不压缩过度 |
| 缺少音视频/图片资质 | 本项目的语音是用户自己录制并本地保存，不做内容分发，属于工具能力，不涉及音视频内容类目 |
