## 二、v1.8.5 提审表单：逐项填法

后台「提交审核」是一张表单，实测（2026-11-26 截图）只有**一个文本框**，且它自己写着
「所填信息只用于审核，不会展示给用户」。所以之前说的「给用户看的版本更新说明」在这一步并不存在——
真实约束只有一条：**版本描述 200 字，含标点**（框右下角实时计数）。

### 2.1 版本描述（168 字，实测未超限，整段复制）

```
纯本地笔记工具：不登录、无服务端，内容只存本机不上传，首次打开为空列表属正常。1.8.5新增：灵感模板库（25个内置模板＋使用指南）、按日期整组归档与撤销、做成图加产品名与小程序码。验证：首页输入即存；我的→灵感模板库→任选一条→用这个模板记一条。权限：麦克风、相册、剪贴板，已在隐私指引声明。模板为内置静态文案，无用户上传与评论入口。
```

为什么是这五段而不是流水账：定位（不用担心我没账号）→ 新增（能点到的）→ 验证路径（照着点）→ 权限一句 → UGC 定性（防追问）。200 字装不下编号清单，所以全部压成一句话，用「；」分句。

**提交前先删掉框里原有的那句**。截图里现在是
「优化保存入口布局与多张照片长图生成，修复语言切换后的文案显示。」——那是 1.8.4 留下的，
和这一版无关。审核员按这句话去比对 1.8.5 的包，会觉得描述与实物不符。

### 2.2 其余字段

| 字段 | 选什么 | 依据 |
|---|---|---|
| 图片预览（选填） | **建议传 3～4 张**：① 记一条（含录音/拍照）② 列表分组 ③ 灵感模板库列表 ④ 我的（能看见版本号 1.8.5） | 空首页是最容易被判「功能不完整」的地方，截图比文字管用；上限 10 张、单张 ≤5M、jpg/jpeg/bmp/gif/png |
| 视频预览（选填） | **不传** | 录屏要 mp4、≤20M，收益低于维护成本 |
| 测试账号 | **无需登录账号即可使用** | 本项目没有账号体系 |
| 小程序订单中心 path | **留空** | 提示写的是「交易类小程序需提交」，本版无任何支付与订单。**1.8.6 接入虚拟支付后这一项必须填，否则代码审核不通过**——先记在这里，别到时候才发现 |
| 审核加急 | 不选 | 个人主体通常没有加急通道（推断，未在后台实测到该选项是否可选） |
| 用户隐私保护指引设置 | 保持**采集用户隐私** | 录音、相册、剪贴板三项都要在指引里。点「点击更新用户隐私保护指引」进去确认这三项还在，别只看着是绿点就提交 |

### 2.3 审核员若追问「模板库是不是 UGC / 内容服务」

版本描述里已经压进最后一句（「模板为内置静态文案，无用户上传与评论入口」）。若仍被追问，用这段：

> 模板是开发者内置的写作提纲，随代码包发布，不经过任何服务端；没有用户上传、发布、评论入口；
> 用户点「用这个模板记一条」只是把一段固定文本复制进本机编辑页，生成的内容只存在用户自己手机上。
> 功能本质仍是「备忘录 + 提示词」，不构成内容服务。

### 2.4 一次自我更正

上一版这份文档里说「升级提审会出现版本更新说明框、给用户看」——**这是错的**（依据是 1.8.4 提审时的印象，没有原文）。
从 1.8.5 的表单截图看，提交审核只有「版本描述」一个框，且明确写着不展示给用户。

## 五、写「版本描述」的固定骨架（下次照抄）

**硬约束先记住：200 字，含标点，框右下角实时计数。** 一旦要压字数，先砍"本次新增"的条数，再砍细节，绝不砍三样：空态说明、验证路径的入口名、权限那句。因为驳回最常见的两个理由是"功能不完整"和"隐私未声明"，砍掉这两样等于自找。

顺序固定为五段，用「；」连成一段，不用编号（编号太占字）：

1. **定位**：是什么 + 不登录/无服务端。第一句就要让审核员知道不需要账号。
2. **新增**：只写能点到的界面变化，不写"优化体验""提升稳定性"——空话审核员无法验证，只会更想找问题。
3. **验证路径**：从哪个入口 → 点什么 → 应看到什么。**空列表必须在这里解释**，否则容易被判功能不完整。
4. **权限一句**：哪个权限、干什么、数据去哪。三个权限一行写完。
5. **公开页定性**：有没有用户上传、发布、评论。含糊比承认更危险。

四条禁忌：

- 不要承诺代码里没有的能力（指南曾写"转成文字需要联网"，就是反面例子）。
- 不要写内部代号（"第 49 章""reflow 重构"审核员看不懂）。
- 不要自相矛盾：既说"不联网"又说"语音转文字需要联网"。1.8.5 起口径是**记录与录音不上传，语音不做转文字**。
- 不要留着上一版的话不删。表单会记住上次填的内容，**每次都要整段替换**——1.8.5 提审时框里还躺着 1.8.4 那句。
