## 二、v1.8.5 后台要填的两个框（可直接复制）

后台提交审核时会出现两个不同的输入框，**面向的读者不一样**，不要写成同一段话：

- **版本描述**：给审核员看的，要能照着点通。
- **版本更新说明**：升级提审才有（1.8.4 首发时确认过没有这个框），是给用户看的更新日志，一句话一条即可。

### 2.1 版本描述（给审核员，整段复制）

```
本小程序为纯本地灵感记录工具：不注册、不登录、无服务端，所有内容由用户本人创建并只保存在本机，
不上传、不同步。因此首次打开为空列表属正常，不是功能缺失。

本次 1.8.5 为功能更新，新增：
1. 「灵感模板库」：25 个内置写作/记录模板，按 5 类编排，用户可在记录页一键把模板正文带进编辑页照着写；
2. 「使用指南」：一页说明文字，讲清三种记法、数据存放位置、换手机怎么搬；
3. 首页分组头新增「归档」，可按日期整组归档与取消归档，误操作有撤销条；
4. 「做成图」页脚补充产品名与小程序码，便于用户自己保存分享；
5. 首屏空态增加一行说明（只存在这台手机、不上传、不用登录）。

验证路径：
1. 首页「今天想到什么？」→ 输入任意文字 → 保存 → 返回列表可见；
2. 首页「＋」→ 录音 / 拍照 → 保存后可播放、可预览；
3. 首页右上「我的」→「灵感模板库」→ 任选一条 → 点「用这个模板记一条」→ 正文已带入编辑页；
4. 首页列表按日期分组 → 分组头点「归档」→ 该组移入「归档」筛选 → 点底部撤销条可恢复；
5. 「我的 → 关于小程序」可查看版本号 1.8.5 与联系方式。

权限用途：麦克风（录语音灵感）、相册（选照片）、剪切板（把复制的文字一键存为灵感），
均已在《用户隐私保护指引》中声明，数据仅保存在本机，不上传。

说明：模板库与使用指南为**内置静态内容**，由开发者撰写，随代码包一起发布；
不提供任何用户发布、上传、评论、点赞入口，不存储任何用户内容，也不做内容分发。
```

### 2.2 版本更新说明（用户可见，整段复制）

```
1. 新增灵感模板库：25 个写作与记录模板，覆盖灵感捕捉、故事写作、周报复盘、会议纪要、读书笔记；
2. 新增使用指南，讲清三种记法、数据存在哪、换手机怎么搬；
3. 列表分组头可整组归档，误操作可一键撤销；
4. 做成图带产品名与小程序码，方便保存和分享；
5. 修复英文界面下部分标题显示不全的问题。
```

> 第 5 条写"修复显示不全"而不是"修复若干问题"——用户能对上自己遇到过的那件事，审核员也不会因为含糊而追问。

### 2.3 审核员若追问「模板库是不是 UGC / 内容服务」

口径（与版本描述最后一段一致，不要临场组织语言）：

> 模板是开发者内置的写作提纲，随代码包发布，不经过任何服务端；没有用户上传、发布、评论入口；
> 用户点「用这个模板记一条」只是把一段固定文本复制进本机编辑页，生成的内容只存在用户自己手机上。
> 功能本质仍是「备忘录 + 提示词」，不构成内容服务。

## 五、写「版本描述」的固定结构（下次照抄这个骨架）

1. **一句定位**：是什么、给谁、不联网不登录。第一句就要让审核员知道你不需要账号。
2. **本次新增 3～5 条**：只写能点到的界面变化，不写"优化体验""提升稳定性"——审核员无法验证空话，只会更想找问题。
3. **验证路径**：编号，每条都是"从哪个入口 → 点什么 → 应看到什么"。空态页面必须在这里解释，否则容易被判"功能不完整"。
4. **权限用途一句话**：哪个权限、用来干什么、数据去哪。三个权限一行写完，不要展开成长段落。
5. **涉及公开页时的定性**：有没有用户上传、发布、评论。有就如实说，没有就明确说"没有"——含糊比承认更危险。

三条禁忌：

- 不要在版本描述里承诺代码里没有的能力（1.8.5 之前指南曾写"转成文字需要联网"，就是个反面例子）。
- 不要写版本号之外的内部代号（"第 49 章""reflow 重构"审核员看不懂）。
- 不要在同一份描述里既说"不联网"又说"语音转文字需要联网"——自相矛盾会引来追问。1.8.5 起的口径是：**记录与录音不上传，语音不做转文字**。
